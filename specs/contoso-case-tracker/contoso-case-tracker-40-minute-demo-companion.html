Live-demo recovery

Environment or authentication fails

Stay in VS Code. Show the planning artifacts and script boundaries, explain what authentication unlocks, and state that no deployment claim is being made.

Case data is missing

Use a prepared record if available. Otherwise show the Case form design and Active Cases definition, then label the record outcome as the next live validation.

View or dashboard is unavailable

Use solution inventory or scenario requirements as design evidence. Do not describe the surface as deployed until it is visible in the target environment.

Preflight checklist

  • Open VS Code, Copilot Chat, scenario files, terminal, Maker portal, app, and a prepared Case record.
  • Run a timed rehearsal and fix the scenario mismatch in demo-dry-run.md.
  • Confirm the target solution and publisher prefix before authentication.
  • Verify the Case form, Active Cases view, supervisor dashboard, and sample data before claiming success.
  • Keep a static screenshot or exported evidence package available for a controlled fallback.
